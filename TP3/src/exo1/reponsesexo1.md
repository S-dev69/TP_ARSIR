# Exercice 1 : Naviguez et Requêtes HTTP

## Q1 : Messages associés aux codes HTTP

En consultant l'URL `http://perdu.com` via l'inspecteur réseau du navigateur, voici les messages standard associés aux codes demandés :

* **200** : `OK` — La requête a réussi avec succès.
* **404** : `Not Found` — La ressource demandée est introuvable sur le serveur.
* **418** : `I'm a teapot` — Code d'erreur humoristique (spécifié dans la RFC 2324).
* **502** : `Bad Gateway` — Le serveur agissant comme passerelle a reçu une réponse invalide.
